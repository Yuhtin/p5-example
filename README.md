# SOL (Wall Drawing #370)

Recriação em p5.js do "Wall Drawing #370" do Sol LeWitt (1928-2007), um artista americano do minimalismo e da arte conceitual. Trabalho feito pra disciplina da professora Bruna Mayer, que pediu pra cada um escolher uma obra e recriar com código. Para isto, usei p5.js, uma biblioteca JavaScript pra desenho criativo no navegador, é muito usada em arte generativa, ensino de programação e prototipagem visual.

## Animação

As listras correm devagar enquanto o sketch roda. As horizontais descem, as verticais andam pra direita, e dentro dos recortes o sentido é perpendicular ao da moldura (o miolo do O desce enquanto a moldura desliza lateral, por exemplo). A velocidade é controlada pelo `driftSpeed` no topo do `sol.js`.
